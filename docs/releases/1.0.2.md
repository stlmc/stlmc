# 1.0.2

## 1.0.2.dev1

- Require CPython 3.11–3.14 and pin solver and visualization dependency profiles managed by `stlmc-installer`.
- Install official Yices 2.7.0 archives with a managed CUDD dependency on supported Linux systems; check native capabilities before activation.
- Add component removal with `stlmc-installer uninstall` and `--dry-run`, preserving system installations, modified files, and user outputs.
- Correct post-jump proposition matching and sampled robustness at shared segment endpoints.
- Support Boolean equality and inequality in STL goals, including proposition aliases such as `pix = false`.
- Apply segment-duration limits consistently across solver backends and preserve invariant identifiers across multi-digit bounds.
- Support exact polynomial ODE lowering for compatible algebraic backends and independent scenario and unsat-core solver selection.
- Use Matplotlib for PDF output and Bokeh for interactive HTML, with counterexamples and witnesses stored as compressed JSON instead of pickle.
- Consolidate installation and testing documentation and keep the quick-start path focused on installation, verification, and visualization.
- Add non-publishing Linux/macOS compatibility checks and isolated benchmark timing diagnostics.
- Include a browser workspace and authenticated local bridge through `stlmc-gui`, with optional dependencies managed by `stlmc-installer install --ui`.
- Read workspace defaults and goal labels through the CLI's configuration loader and model parser; display parser diagnostics in MIT-licensed CodeMirror 6 editors.
- Add model/config file watching, finished-run history removal, custom storage folders, and explicit `--no-auth` mode for trusted single-user local sessions.
