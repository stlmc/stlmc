# 1.0.1

## 1.0.1.dev4

- Select an installed, supported runtime for `solver=auto`, checking only selected goals; report unavailable candidates instead of silently installing or changing an explicitly selected solver.
- Restore default downloads of the official dReal 3.16.06.02 release with known-bug warnings. Allow `check` and verification to proceed with warnings for its known invariant limitation, while retaining errors for unrelated failures; successful installation or checking does not certify ODE correctness.
- Gate private-prefix dReal source builds behind explicit `--experimental-build`, accepting Linux x86-64 with GCC only. Linkage and feature checks do not certify general ODE soundness; known upstream witness defects remain. All macOS builds are currently rejected.
- Enforce the common `time-horizon` segment-duration limit for all solver backends, including final two-step refinement; earlier versions applied it only to dReal inputs.
- Preserve complete module, invariant-atom, and bound identifiers, including multi-digit bounds, so later invariant definitions cannot overwrite earlier ones.
- Preserve numeric mode identifiers and declared types during proposition matching and refinement; support their discrete sampled values in visualization and robustness evaluation.
- Lower supported autonomous polynomial ODEs with acyclic state dependencies to exact closed-form constraints instead of Euler approximations; reject unsupported ODEs in algebraic backends rather than silently approximating them.
- Flatten redundant Boolean connectives consistently in CLI, text, and LaTeX displays without changing the solver encoding or structural formula identifiers.
- Retune selected artifact goals with shorter regression windows and explicit predicate/operator changes; their results do not establish the historical verification scope.
- Correct polynomial battery flows using rate-integrated cubic solutions and a mode-local clock preserved across STL partition points; this is a revised model, not an equivalent rewrite of the historical input.
- Manage external solvers and visualization dependencies with `stlmc-installer install` and `stlmc-installer check`.
- Solver and plotting packages are installed separately from the base STLmc package. The installer checks supported dependency versions.
- Replace the former solver-only installer command with `stlmc-installer`.
- Support independent scenario-generation and unsat-core solver backends.
- Report unavailable solvers and unsafe parallel Yices configurations with actionable errors.
- Validate inconsistent flow initial values before starting verification.
- Generate PDF plots with Matplotlib instead of Gnuplot; retain optional Bokeh HTML output.
- Display the package version and source commit in help, version output, and verification headers.
- Store counterexamples and reachability witnesses as versioned, gzip-compressed JSON while retaining the `.counterexample` and `.witness` extensions; reject outdated pickle files with instructions to regenerate them.
- Official dReal downloads target Linux x86-64 and the Intel macOS release; Apple Silicon requires an existing Rosetta installation. Native ARM64 installation is not provided.

## 1.0.1.dev3

- Add symbolic and explicit discrete-path strategies, composable with one-step and two-step solving.
- Implement state reachability through the regular bounded model-checking engines, with bounds counting jumps and witnesses written separately from STL counterexamples.
- Add solver-query batching and configuration options for batch size and scenario-core search attempts.
- Validate solver arithmetic capabilities before solving and report unsupported operators separately from solver `unknown` results.
- Update Boolean, arithmetic, and robustness-expression translations and temporal interval handling.
- Add structured verification messages, SMT2 query export, and subprocess cancellation and cleanup handling.
- Add the solver-only installer command `stlmc-install-solvers`, including dReal executable discovery and installation support.
- Pin the Z3 Python dependency to `4.13.2.0` and declare CPython 3.8–3.14 package compatibility.
- Add benchmark fixtures, artifact-based benchmark execution, solver comparisons, and solver smoke tests.
- Remove the former reachability implementation and unused external-tool adapters.
- Update release packaging and Linux/macOS workflow configuration.

## 1.0.1.dev2

- Update the Sigstore distribution-signing action from `v2.1.1` to `v3.4.0` and increment the package version.

## 1.0.1.dev1

- Apply substitutions inside unary expressions.
- Preserve both Boolean polarities when generalizing scenarios and implement the non-generalized scenario path selected by `concrete`.
- Reset solver runners between queries, propagate unresolved solver results as `unknown`, and clean up workers when verification raises an exception.
- Handle absolute and relative dReal executable paths separately.
- Set the default dReal integration order to 20 and leave the step size unspecified for automatic control.
- Remove the `termcolor` dependency and update package and release-build metadata.
